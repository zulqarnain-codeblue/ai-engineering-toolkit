# Skill: Frontend Quality

- Inspect the existing design system before introducing new visual patterns.
- Identify typography, spacing, colors, layout, component variants, and interaction conventions.
- Design the full state model: loading, empty, success, error, disabled, and permission-denied.
- Use semantic HTML, accessible names, keyboard support, visible focus, and reduced-motion support.
- Test responsive behavior at representative viewport sizes.
- Avoid generic gradients, excessive cards, arbitrary animations, and decorative UI that harms clarity.
- Use motion to explain state or hierarchy, not merely to add spectacle.
- Verify in a browser for meaningful UI changes.
- Report actual viewports and flows tested.
