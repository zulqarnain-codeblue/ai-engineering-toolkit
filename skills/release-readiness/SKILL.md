# Skill: Release Readiness

Before release, review:
- Acceptance criteria and known limitations
- Test, lint, typecheck, build, and security results
- Database migration and backward compatibility
- Environment variables and secret handling
- Logging, monitoring, health checks, and alerts
- Backup and rollback plan for risky changes
- Documentation and operator instructions
- Feature flags and staged rollout options where useful
- Data/privacy implications and access control

Do not deploy or modify production unless authorized. Report blockers and unverified checks plainly.
