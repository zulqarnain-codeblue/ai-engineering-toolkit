# Pack Selection Matrix

| Signal | Recommended pack |
|---|---|
| React, Next.js, Vite React | `react-nextjs` |
| Laravel, PHP API, queues | `laravel-php` |
| Shopify theme / Liquid | `shopify` |
| LLM feature, prompts, agent workflows | `ai-applications` |
| iOS/Android or React Native | `mobile` |
| ETL, analytics, data models | `data-engineering` |
| Deployment, containers, CI/CD | `infrastructure` |
| Auth, payments, sensitive data, public API | `security` |

Multiple packs may apply. Select by evidence, not by guesswork. A Laravel + React SaaS may use `laravel-php`, `react-nextjs`, and `security`, for example.
