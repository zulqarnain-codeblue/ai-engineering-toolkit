# Profile: New Product

Use for a new application, SaaS, or major greenfield project.

## Required discovery
- Target user and problem
- Primary job-to-be-done
- Differentiator and why users would choose it
- Core journeys and acceptance criteria
- MVP scope and explicit non-goals
- Data model and permissions
- Integration and operational constraints
- Success measures and risks

## Deliverables before substantial implementation
1. Product brief
2. MVP feature list and non-goals
3. User journeys
4. Architecture/data/API outline
5. Design-system direction if UI exists
6. Testing and security strategy
7. Phased implementation plan

Do not over-specify a prototype. For a production-bound product, resolve high-impact unknowns before coding the foundation.
