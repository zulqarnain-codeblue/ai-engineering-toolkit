# Profile: Bug Fix

1. Capture expected vs actual behavior.
2. Reproduce the issue or identify the strongest available evidence.
3. Trace the cause; avoid symptom-only patches.
4. Add a regression test where practical.
5. Implement the smallest safe fix.
6. Run focused tests and adjacent regression checks.
7. Report cause, fix, checks, and any remaining uncertainty.

Do not silently expand scope into unrelated refactors.
