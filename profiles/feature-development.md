# Profile: Feature Development

1. Clarify the outcome and acceptance criteria.
2. Inspect related components, APIs, schema, tests, and existing patterns.
3. Identify compatibility, security, performance, and migration risks.
4. Split work into small vertical slices.
5. Implement each slice with tests.
6. Validate relevant user journeys and error states.
7. Update docs and report evidence.

For cross-cutting changes, define the contract between frontend, backend, data, and external services before parallel implementation.
