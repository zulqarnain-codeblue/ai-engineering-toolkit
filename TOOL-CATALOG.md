# Tool Catalog

Use this as a shortlist, not an installation checklist.

| Capability | Repository/tool | Use when |
|---|---|---|
| Reverse-engineering research | [REA](https://github.com/morluto/rea) | Investigating reference products/features |
| Agent workflow | [Superpowers](https://github.com/obra/superpowers) | Disciplined feature implementation |
| Specification-driven work | [Spec Kit](https://github.com/github/spec-kit) | New products / substantial features |
| Reusable skills | [Anthropic Skills](https://github.com/anthropics/skills) | Task-specific skill patterns |
| React performance | [Vercel Agent Skills](https://github.com/vercel-labs/agent-skills) | React/Next.js projects |
| Versioned documentation | [Context7](https://github.com/upstash/context7) | Version-sensitive library usage |
| Browser automation | [Playwright MCP](https://github.com/microsoft/playwright-mcp) | Browser exploration and UI checks |
| Security skills | [Trail of Bits Skills](https://github.com/trailofbits/skills) | Security-focused review |
| React components | [shadcn/ui](https://github.com/shadcn-ui/ui) | Optional component foundation |
| Component workshop | [Storybook](https://github.com/storybookjs/storybook) | Shared UI libraries |
| Accessibility testing | [axe-core](https://github.com/dequelabs/axe-core) | Automated accessibility checks |
| JS testing | [Vitest](https://github.com/vitest-dev/vitest) | Compatible JS/TS projects |
| PHP tests | [Pest](https://github.com/pestphp/pest) | Laravel/PHP tests |
| PHP static analysis | [Larastan](https://github.com/larastan/larastan) | Laravel static analysis |
| PHP formatting | [Laravel Pint](https://github.com/laravel/pint) | Laravel/PHP code style |
| Shopify theme checks | [Theme Check](https://github.com/Shopify/theme-check) | Liquid theme validation |
| LLM evaluation | [promptfoo](https://github.com/promptfoo/promptfoo) | Prompt/model regression and security evaluation |
| Agent orchestration | [LangGraph](https://github.com/langchain-ai/langgraph) | Stateful multi-step AI workflows |
| Mobile | [Expo](https://github.com/expo/expo), [Maestro](https://github.com/mobile-dev-inc/maestro) | Mobile app development and UI automation |
| Data transformations | [dbt Core](https://github.com/dbt-labs/dbt-core) | Analytical data workflows |
| Data quality | [Great Expectations](https://github.com/great-expectations/great_expectations) | Data pipeline assertions |
| Artifact scanning | [Trivy](https://github.com/aquasecurity/trivy) | Relevant dependency/container/config scans |

Check each project's current documentation, support, license, security posture, and install process before adoption.
